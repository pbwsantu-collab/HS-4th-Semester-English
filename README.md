# HS 4th Semester English

Premium educational PWA landing page — central launchpad for HS 4th Semester English lessons.

**Live:** [Open on GitHub Pages](https://pbwsantu-collab.github.io/HS-4th-Semester-English/)

## Lessons

1. [Alice in Wonderland](https://pbwsantu-collab.github.io/Alice-in-the-Wonderland-/#laq)
2. [Hawk Roosting](https://pbwsantu-collab.github.io/Hawk-Roosting/)
3. [Three Questions – Leo Tolstoy](https://pbwsantu-collab.github.io/three-questions-tolstoy-pwa/)
4. [Sonnet 73 – Shakespeare](https://pbwsantu-collab.github.io/sonnet-73-master/)
5. [Greenhouse Effect](https://pbwsantu-collab.github.io/greenhouse-effect-master/)

## Stack

Static PWA: HTML · CSS · Vanilla JS · `manifest.json` · Service Worker  
No build tools required. Deploy with GitHub Pages.

## Enable GitHub Pages

1. Repo **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / root
4. Save — site will be at `https://pbwsantu-collab.github.io/HS-4th-Semester-English/`
